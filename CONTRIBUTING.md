# Contributing

Thanks for your interest. patchbot is a personal project in early development, and its code runs with credentials, so
changes are accepted carefully.

- Open an issue first to discuss any change. Unsolicited pull requests may be closed without review.
- All changes go through a pull request into `development`; `main` only receives reviewed releases.
- Every pull request must pass CI and be approved by a code owner (see `.github/CODEOWNERS`).
- CI for pull requests from forks runs only after a maintainer approves it.
- Do not add dependencies, GitHub Actions or workflow changes without discussing them first.
- Report security problems privately, as described in `SECURITY.md`, never in an issue or pull request.
