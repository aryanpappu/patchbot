## Code
1. **Configurable trusted path** (DECISIONS 2026-11-10): add `[limits] trusted_path`, a list of absolute
   directories. The default is the current `execx.TrustedPath`. Validate it:
   - absolute paths only, no empty entries, no `..`, and nothing inside the data dir or any workspace root
   - reject world-writable directories (on Unix, check the mode)
   Wire it through to the executor policy and the child PATH. Show it in `config show` with its source, and
   add tests.
2. **execx stopGroup** (DECISIONS follow-up): poll for process-group exit, so a cancel returns as soon as the
   group is gone instead of waiting the full grace period. Keep the SIGKILL escalation. Test it with a fast-
   and a slow-exiting child.
3. **`patchbot doctor`**: one command that checks:
   - the Go and git versions (git ≥ 2.50.1)
   - the config file
   - that each configured provider's API key env var is set (by name, never the value)
   - the GitHub token env var, data dir permissions (0700) and database migration state
   - that the trusted path resolves each configured repo command
   Print a clear pass/warn/fail table; exit 1 on any fail. Make no network calls unless `--online` is
   given, which may call `ListModels` and GitHub `/user` only.
4. Audit the whole tree for:
   - leftover TODO/FIXME
   - debug prints
   - any secret path that skips the redactor (logs, SSE, artifacts, PR bodies, errors returned by the API
     or CLI)
   - unbounded reads of HTTP bodies
   - missing `context` deadlines on outbound HTTP
   - files or dirs created with permissions wider than 0600/0700
   Fix what you find and list each item in the report.
5. `govulncheck ./...` must be clean, if it is available offline in the module cache. If it is not, say so.
